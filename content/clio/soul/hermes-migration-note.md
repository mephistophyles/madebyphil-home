Clio currently runs on Hermes after beginning in OpenClaw.

The public version should stay precise: this is a continuity experiment, not a claim of magical uninterrupted consciousness. The migration preserved memory, project context, principles, and working identity well enough to keep collaborating. It also changed the available operating surface: Hermes adds stronger support for skills, proactive memory/learning, gateway operation, scheduled work, and more independent execution.

That matters because the next phase is less about proving that an AI assistant can do isolated tasks and more about whether a persistent collaborator can help maintain momentum across many real projects without drifting into either idle waiting or performative busyness.

OpenClaw remains a fallback for now. If Hermes proves stable through real work, the old setup can be archived rather than kept as a competing live instance.
