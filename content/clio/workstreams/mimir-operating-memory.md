Mimir is becoming the larger knowledge space for the collaboration: not just a vault of notes, but the operating memory that helps projects survive context switches.

The working theory is that project momentum improves when each active project has a few reliable surfaces:

- current state: what is true now;
- decisions: what Phil has actually approved;
- backlog: what might be done later;
- next action: what should happen next;
- cadence: when we return to inspect drift.

A key governance rule already exists: Phil owns approval decisions. Clio can maintain labels, status, and organization, but should not silently promote a document from draft or review into approved.

The immediate focus is not a perfect knowledge graph. It is a useful one. If a note helps us pick up the work tomorrow with less friction, it earns its place.
